Wasteland 3 Save Editor

Open a save

Use at your own risk. This editor hasn't been thoroughly tested. Back up your save folder before you start.
  1. Go to your saves folder (pick your system below and copy the path).
  2. Each save there has its own folder, named after the save. Open the one you want.
  3. Drag the .xml file inside it onto this page, or click Open save… and pick that file.

The .xml file is the save itself. When you're done, you'll put the edited one in its place.

The save is read in your browser and never uploaded anywhere.

All three edit the same save. Changed values are highlighted in Tree and Raw XML.

How to use it

  1. Back up your save folder first.
  2. Open the save's folder and drag the .xml file inside it onto the page, or click Open save… and pick it. See where saves are kept.
  3. Make your changes. Download save shows a list of everything you changed before it saves.
  4. Copy the downloaded file over the original .xml, keeping the same name.

Views

Editor
Forms for money, scrap, fame, your squad (stats, skills, perks, mutations, gear), the inventory, the Kodiak, collectibles, faction reputation and story flags.
Tree
Every value in the save. Search by name (e.g. money) or by value, click a value to edit it, ⧉ duplicates and ✕ deletes. Duplicated items get a new uid.
Raw XML
The save's XML in a text editor. Ctrl+F searches. Edits are checked when you switch away or download, and invalid XML is never applied.

Other tabs

Codes
Every item, outfit, perk, quirk, ability and status effect, with buttons to add them to your save. Names come from the game's own text. Pictures come from the community wiki.
Compare
See what changed between two saves and copy those changes into another.

Shortcuts

  • Ctrl K search everything
  • Ctrl Z undo, Ctrl Y redo (outside text boxes)

FAQ

Is it safe to use?
Your save never leaves your computer. It hasn't been thoroughly tested though, so keep a backup. The "+ backup (.zip)" download includes one.
Where are my saves?
Can I edit console saves?
Only if you can get the save file onto a computer. The editor works with the PC save files on Windows, Mac and Linux.
The game won't load my edited save. What now?
Put the backup back and redo your changes a few at a time to find the one causing it. Values far above normal, like attributes over 10, are the usual suspects.
My change didn't show up in game.
Check you copied the downloaded file over the original .xml with exactly the same name, and that you loaded that save. If you use Steam Cloud, it may have put back an older copy.
Why is the downloaded file smaller?
The editor compresses the save a little better than the game does. The contents are the same.
Why do some items show a question mark?
Pictures only come from a wiki page with exactly the item's name, and many items don't have one.
Can I undo after downloading?
Undo works until you close the page. After that, use your backup.

Good to know

  • Attributes and skills normally go up to 10. Higher may work but hasn't been tested.
  • Raising skills or adding perks here doesn't give what levelling them in game does, like crafting recipes. Give unspent points and spend them in game instead.
